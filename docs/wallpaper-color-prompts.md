# Wallpaper color variants

These project assets were created with the built-in image-generation tool in edit mode, using `theme/backgrounds/tux-crimson-eclipse.png` as the edit target. The original crimson wallpaper remains unchanged. Each variant was visually inspected for the same scene, Tux pose, eclipse placement, and matching illumination.

Saved files:

- [Original red](../theme/backgrounds/tux-crimson-eclipse.png)
- [Blue](../theme/backgrounds/tux-blue-eclipse.png)
- [Green](../theme/backgrounds/tux-green-eclipse.png)
- [Yellow](../theme/backgrounds/tux-yellow-eclipse.png)
- [Pink](../theme/backgrounds/tux-pink-eclipse.png)
- [Purple](../theme/backgrounds/tux-purple-eclipse.png)

One built-in edit call was made per variant. This exact prompt template was used with `COLOR` replaced by blue, green, yellow, pink, and purple; the first color occurrence was uppercase:

> Use case: lighting-weather edit. Asset type: Linux desktop wallpaper color variant. Edit target: the provided original crimson eclipse/Tux wallpaper. Make a COLOR accent variant by changing ONLY the red/crimson emissive eclipse rim, sky/cloud highlights, reflected light, rivers and rock edge illumination to luminous COLOR, with near-black shadows retained. Preserve exactly the same scene composition, penguin identity and pose, mountain silhouettes, camera framing, eclipse placement, detail, aspect ratio, and overall darkness. Keep the penguin black/white with its natural orange beak and feet. This is a color-only variant, not a new scene. No text, watermark, UI or extra objects.

Existing attribution/licensing notes in the repository README still apply. The installer ships these PNGs directly; it does not call an image API or edit raster images on the user's machine.

## Halloween Tux variant

Generated with the built-in imagegen tool by editing the original Tux/crimson eclipse wallpaper. Final prompt:

Built-in imagegen edit of existing Tux eclipse wallpaper. Preserve seated Tux and eclipse composition; pumpkin-orange lighting, purple fog, bats, and two jack-o-lanterns beside Tux. Dark cinematic Halloween mood, no text.

## Thanksgiving and Christmas Tux variants

Both wallpapers were edited from the original Tux/crimson eclipse wallpaper using the built-in imagegen tool. Final prompts:

### Thanksgiving

Edit this Tux Linux wallpaper into a tasteful Thanksgiving autumn desktop wallpaper. Preserve the seated black-and-white Tux penguin on the left cliff, looking toward the huge eclipse on the right, same wide cinematic black rocky landscape composition. Warm amber-gold eclipse, burnt orange sunset light, copper and deep brown atmosphere, subtle golden autumn leaves near Tux and two small natural uncarved harvest pumpkins plus a few autumn leaves on his cliff. Warm elegant harvest mood, atmospheric golden mist, dark negative space. Keep recognizable Tux, orange beak and feet. No bats, no jack-o-lanterns, no text, no watermark.

### Christmas

Edit this Tux Linux wallpaper into a beautiful Christmas winter desktop wallpaper. Preserve recognizable seated black-and-white Tux penguin on left cliff looking toward huge eclipse on right, same cinematic wide mountain landscape composition. Tux wears a small classic red Santa hat. Snow blankets cliff edges and distant mountains, icy starlit night, eclipse glows warm golden with subtle red light, deep evergreen shadows. A small decorated evergreen beside Tux with warm gold and red twinkle lights, restrained red ornaments, gentle sparse snowfall. Elegant cozy Christmas atmosphere with near-black dark negative space. Preserve Tux orange beak/feet. No text, no watermark, no pumpkins, no bats.
